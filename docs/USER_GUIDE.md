# Clothwork user guide

Clothwork helps users prepare and review classic clothing metadata. Saving changes happens through Roblox Creator Hub.

## Install

1. On GitHub, choose **Code → Download ZIP**.
2. Extract the ZIP to a folder on your computer.
3. Open `chrome://extensions` in Google Chrome.
4. Enable **Developer mode** and click **Load unpacked**.
5. Choose the extracted directory containing `manifest.json`.

## Use Clothwork

1. Open Roblox Creator Hub and sign in normally.
2. Open Clothwork, enter a group ID, and select **Check group**.
3. Load the clothing inventory and select items to review.
4. Enter your new name and description, then select **Preview changes**.
5. In the clothing list, select **Copy name** or **Copy description** next to an item.
6. Use **Open in Roblox** to visit the item's configuration page.
7. Paste and save the text using Roblox's controls.
8. Return to Clothwork and select **Mark saved** after verifying the update.

Repeat steps 5–8 for each item. Clothwork does not submit edits automatically.

## Notes

- Blank lines and paragraph spacing are preserved when copying descriptions.
- Inventory loading depends on Roblox's availability and may change.
- If an item link changes, open the asset in Creator Hub manually.
- Do not share passwords, session cookies or private creator exports.
